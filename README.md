# Minha Escala — PWA

Escala 14x14 com data-base **15/10/2026**, primeiro dia de serviço.

## Funcionalidades
- Calendário anual com navegação entre anos.
- Serviço em vermelho, folga em verde e alterações manuais em laranja.
- Edição de data, observação, restauração individual e restauração geral.
- Exportação e importação de backup JSON.
- Cache para uso offline após abrir o app uma primeira vez com internet.

## Publicar no GitHub Pages
1. Extraia o ZIP no computador.
2. Crie um repositório no GitHub chamado `minha-escala`.
3. Envie os arquivos e a pasta `icons` para a raiz do repositório.
4. Em Settings → Pages, selecione publicação pela branch `main` e pasta `/root`.
5. Abra a URL HTTPS gerada.

## Instalar no iPhone
Abra a URL no Safari → Compartilhar → Adicionar à Tela de Início → Adicionar.

## Armazenamento
Os ajustes ficam localmente no navegador de cada aparelho. Não existe sincronização automática. Exporte o backup em um aparelho e importe no outro para transferir suas alterações.
